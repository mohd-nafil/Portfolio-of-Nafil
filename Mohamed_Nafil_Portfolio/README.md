# Mohamed Nafil N — Portfolio Website

A responsive portfolio website built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — responsive layout, colors, typography, and animations
- `script.js` — mobile menu, current year, and copy-email button
- `Mohamed_Nafil_Technical_Support_Resume.docx` — resume download linked from the page

## Run locally
1. Extract the ZIP file.
2. Keep all files in the same folder.
3. Double-click `index.html` to open it in a browser.

## Before publishing
- Check your phone number and email.
- Replace the LinkedIn placeholder with your real LinkedIn profile URL if you want to add it.
- You can host the folder with GitHub Pages or another static website host.
- The contact button opens the visitor's email app; it does not submit to a server.
